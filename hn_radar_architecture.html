AGENTS.md Factory Rules & Quality Gate

The 10 foundational rules and verification checks governing automated agent runs and human reviews.

Rule # Rule Name Description & Rationale Enforcing Components
Rule 1 Every claim is cited Any pulse item or outreach reason stating what users said must carry the comment ID. Why: "Arrive with the fix" requires 100% trust; zero invented feedback. pulse/cluster.py, match.py, closed.py
Rule 2 LLM output schema-validated Parse model responses only through Pydantic models; never regex free text. Small models drift in format; validation surfaces errors immediately. pulse/schema.py, sources/ollama.py
Rule 3 Network in sources/ All HTTP calls to Algolia and GitHub live in src/hnradar/sources/ with disk caching. Tests never hit real network. sources/hn.py, sources/github.py, sources/ollama.py
Rule 4 Untrusted URLs in sandbox Never fetch URLs taken from an HN post, comment, or profile outside the sandbox layer. showhn.py (host_matches only parses, never fetches)
Rule 5 Minimal personal data Store only public GitHub usernames and derived repo stats. Never scrape LinkedIn or store resumes. fingerprint.py, sources/github.py
Rule 6 Limits fail loudly Loops, page caps (2,000 repos), retry caps, and timeouts must raise an error; never return a partial result disguised as complete. sources/github.py, sources/hn.py, pulse/cluster.py
Rule 7 Edge-case tests for every PR Every change ships tests for empty input, at-the-limit, over-the-limit, upstream errors, and concurrent cache writers. tests/, AGENTS.md
Rule 8 Clean untrusted post text Strip Unicode control chars (Cc) and bidi overrides (Cf) before terminal printing; ensure_ascii=True for JSON stdout. cli.py (_terminal_safe)
Rule 9 Domain match != ownership A domain match means a story links to that domain, never that the company posted or owns it. showhn.py, models.py
Rule 10 Upstream errors never complete Failed Algolia, GitHub, or Ollama requests must exit 1 with an error message; never swallow errors into empty results. sources/hn.py, sources/github.py, cli.py

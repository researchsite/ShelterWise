AGENTS.md Invariants & Quality Gate (Definition of Done)

Every change in HN Radar must satisfy these 10 architectural invariants. Qodo review findings of High or Medium severity must be resolved with accompanying tests before PR merge.

Rule # Invariant Name Architectural Enforcement Key Files Enforcing Rule
Rule 1Every claim is citedAny insight or match reason citing user or repo data must record the exact comment ID or repository name.pulse/cluster.py, match.py, draft/write.py, closed.py
Rule 2LLM output is schema-validatedModel completions are constrained and validated through Pydantic models; free-text regex parsing is forbidden.pulse/schema.py, draft/schema.py, sources/ollama.py
Rule 3Network goes through sources/All HTTP operations live in src/hnradar/sources/ and enforce atomic on-disk response caching.sources/hn.py, sources/github.py, sources/ollama.py
Rule 4Untrusted URLs only in sandbox layerURLs in posts or profiles are never fetched over the network; only hostname extraction and sanitization are permitted.showhn.py (host_matches, url_domain)
Rule 5Minimal personal dataStores only public aggregate stats; zero scraping of LinkedIn, resumes, or private repositories.fingerprint.py, sources/github.py
Rule 6Limits fail loudlyPagination caps (2,000 repos) and loops raise hard errors; never return silent partial results.sources/github.py, cli.py (draft cap)
Rule 7Every change ships edge-case testsMandatory unit tests for empty inputs, boundary limits, over-limit inputs, and upstream errors.tests/, AGENTS.md
Rule 8Untrusted post text is cleanedStrips Unicode control characters (Cc) and formatting overrides (Cf) before terminal printing.cli.py (_terminal_safe)
Rule 9Domain match is never company ownershipA domain match confirms only that a story links to that domain, never that the company posted or owns it. Platform domains are flagged.showhn.py, draft/write.py
Rule 10Failed upstream request never completeAPI failures, timeouts, and non-200 responses must exit 1 with an error; never return empty or partial data.sources/hn.py, sources/github.py, cli.py

🛡️ Non-Negotiable Human Decision Gates

1. Ticket Authoring & Acceptance Criteria

Human defines scope, acceptance criteria, and AGENTS.md rules before any code is generated.

2. Local Command Execution

Developer runs uv run pytest, smoke checks, and verify-jobs-parse manually in their local terminal.

3. Qodo Review Triage

Human evaluates Qodo findings, writes regression tests, and commits 'fix: ... review round 1'.

4. Rule 4 Outreach Inspection

CLI prints 5-line draft and comment evidence to stdout. Human inspects and sends manually. Nothing sent automatically.

5. Branch Stack Merge Governance

Human controls merges to main vs branch stacks (e.g. feat/site-careers for careers portal).

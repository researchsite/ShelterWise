    Retrieval Pattern: BigQuery AI.EMBED + VECTOR_SEARCH → Decoy Traps Filter

    -- habitability_vector_ag executes BigQuery AI.EMBED + VECTOR_SEARCH:
SELECT base.request_id, base.block_address, base.property_type, base.inspection_status, base.closed_date,
       ROUND(distance, 4) AS cosine_distance
FROM VECTOR_SEARCH(
  TABLE `a4i_housing.complaints_embedded`, 'embedding',
  (SELECT AI.EMBED(@search_query, connection_id => 'us.a4i-vertex', endpoint => 'gemini-embedding-2').result AS query_vec),
  top_k => 25, options => '{"use_brute_force": true}'
);

    The 8 Grounded Rules (All Tested in Code)

    1. Search wide, then filter: Vector search retrieves candidate semantic hits; Python rules filter out decoys.
    2. Strict Residential Keep Rule: Keep only if property_type == 'Residential', closed_date IS NULL, and status is open.
    3. Zero Decoy Leaks: Never hardcode strings like "DECOY". Filter strictly on business rules (Commercial, Abated, No Violation).
    4. Relief Funds Verification: Unlocks only when every statutory condition is confirmed. Open 311 prerequisite tracked.
    5. Statutory Repair Clocks: Calculates 35-day repair window under CA Civil Code § 1942.4 from citation date.
    6. Eviction Court Grain: Pre-aggregates 4 quarters of court filings per tract before joining ACS data.
    7. 11-Digit Text GEOIDs: Preserves leading zeros (06075...).
    8. Demographic Firewall: audit_* columns are strictly isolated from individual case triage.

    Product & Ethical Guardrails

    • Grounding Before Answer: Every external claim cites BigQuery provenance or is labeled [Tenant-Reported].
    • Absence ≠ Proof: No 311 record on a block never means conditions are acceptable.
    • Block ≠ Unit: A building-wide 311 complaint does not replace unit-specific testimony.
    • Human-in-the-Loop Review: Mandatory 6-item Attorney Review Checklist before filing.
    • No Autonomous Action: No automated filing without paralegal/attorney sign-off.

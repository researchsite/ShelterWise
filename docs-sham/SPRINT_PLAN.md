# Hackathon sprint plan

Planning baseline: 4.5 hours (270 minutes). Adjust to the official event schedule.

| Time | Focus | Exit condition |
|---|---|---|
| 0–20 min | Confirm requirements, metro, scenario, interfaces, owners | One-page scope agreed |
| 20–70 min | Data foundation, agent skeleton, UI shell | Each lane has a running stub |
| 70–130 min | Retrieval, filters, legal/resource lookup, intake extraction | Core tools return typed outputs |
| 130–185 min | Integrate UI → agent → tools → brief | One end-to-end happy path |
| 185–225 min | Test decoys, evidence boundaries, safety, empty states | Critical tests pass |
| 225–255 min | Demo polish, citations, slides, rehearsal | Repeatable demo |
| 255–270 min | Final checks and submission | No last-minute scope additions |

## Execution rules

- Build the vertical slice before polishing individual components.
- Use mocked tool responses only as temporary scaffolding and label them.
- Freeze feature work at the start of the final 45 minutes.
- Keep a known-issues list; do not hide limitations.
- The team lead owns integration and the demo path.
